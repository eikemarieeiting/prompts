# Shot-Prompting gives examples

**What it is**
The prompt includes examples for the output, there are different types:
- One-Shot-Prompting = one example
- Few-Shot-Prompting = Several examples
- Zero-Shot is a prompt without examples

**When to use it**
When you know what you need, specify it. 
For consistency.
